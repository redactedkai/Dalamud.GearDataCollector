Clickable mockup of the window (Interface/MainWindow.cs and Interface/DutyInfoView.cs). Click the title bar arrow to collapse the window. On the Duty / Gear Info tab press Start session: the Note box greys out while the session runs and clears when you press Stop, and the status shows the session status, the session path and the derived gear path. The duty info is a set of sections with a table of every total stat and a table of the Duty Finder settings. Untick "Enable data collection" on the Config tab to see the disabled state. Values are from a Dusk Vigil Min IL session. The window fits its content, as in game. Sizes are multiples of the game font size (20 px, measured from a screenshot) and the text is scaled to the width of the game font, so the layout should be within a few percent of the game; the letter shapes and the colours still differ.
